# 記録を S3 へ送る

聞き取りを停止するたびに、要約と字幕の記録を自分の S3 バケットへ送れます。サーバーは置かず、S3 のバケットと書き込み専用の鍵だけで組みます。

## 設定

1. S3 に非公開のバケットを作ります。
2. IAM ユーザーを作り、次のポリシーだけを付けてアクセスキーを発行します。

   ```json
   {
     "Version": "2012-10-17",
     "Statement": [{
       "Effect": "Allow",
       "Action": "s3:PutObject",
       "Resource": "arn:aws:s3:::<バケット名>/sessions/*"
     }]
   }
   ```

3. アプリの設定画面の「記録の保存先（S3）」に、バケット名とリージョンを入れます。鍵は、アクセスキーIDとシークレットをコロンでつないだ1行で貼ります。鍵は iPhone のキーチェーンに保存されます。

この鍵は書き込みの権限しか持たないので、iPhone を失くしても、鍵からバケットの中身を読まれる心配はありません。

## 置かれる場所

記録は sessions/年/月/ の下に、開始日時を名前にした2つのファイルとして置かれます。機械で扱うための JSON と、人が読むための Markdown です。電波が無いときは iPhone に残り、次の起動か停止のときにまとめて送ります。

## Mac へ取り込む

AWS CLI が入った Mac で、次のコマンドを実行すると手元へ取り込めます。

```bash
HANDY_BUCKET=<バケット名> scripts/handy-pull
```

AWS CLI のプロファイルは `HANDY_PROFILE`、取り込み先は `HANDY_DIR` で指定できます（既定は ~/handy-translator-sessions）。毎回書かずに済ませるなら、~/.config/handy-translator/env に `HANDY_BUCKET=...` の行を書いておきます。
