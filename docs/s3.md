# 記録を S3 へ送る

聞き取りを停止するたびに、要約と字幕の記録を自分の S3 バケットへ送れます。サーバーは置かず、S3 のバケットと書き込み専用の鍵だけで使えます。

## 設定

1. S3 に非公開のバケットを作ります。
2. IAM ユーザーを作り、次のポリシーだけを付けてアクセスキーを発行します。

   ```json
   {
     "Version": "2012-10-17",
     "Statement": [{
       "Effect": "Allow",
       "Action": "s3:PutObject",
       "Resource": "arn:aws:s3:::<バケット名>/sessions/*"
     }]
   }
   ```

3. アプリの設定画面にある「記録の保存先（S3）」に、バケット名とリージョンを入れます。鍵はアクセスキーIDとシークレットをコロンでつないだ1行にして貼り付けます。登録した鍵は iPhone のキーチェーンに保存されます。

この鍵は書き込み権限しか持たないため、iPhone を失くしても、この鍵を使ってバケットの中身を読まれることはありません。

## 置かれる場所

記録は sessions/年/月/ の下に、開始日時を名前にした2つのファイルとして置かれます。機械で扱うための JSON と、人が読むための Markdown です。電波がないときは iPhone に残り、次に起動するか停止したときにまとめて送られます。

## Mac へ取り込む

AWS CLI が入った Mac で、次のコマンドを実行すると手元へ取り込めます。

```bash
HANDY_BUCKET=<バケット名> scripts/handy-pull
```

AWS CLI のプロファイルは `HANDY_PROFILE`、取り込み先は `HANDY_DIR` で指定できます。取り込み先の既定は ~/handy-translator-sessions です。毎回書かずに済ませたいときは、~/.config/handy-translator/env に `HANDY_BUCKET=...` の行を書いておきます。
